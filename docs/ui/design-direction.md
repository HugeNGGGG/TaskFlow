# UI/UX 方向：羊皮纸公会委托板

选定方向（用户确认）：羊皮纸公会委托板 + 混合资产策略（矢量优先、装饰位少量 AI 插画）。

- 关键词：暖羊皮纸、深墨棕、皮革棕、黄铜金、火漆红、苔绿；衬线标题 + 系统黑体正文；扁平实现。
- 签名元素：「悬赏单」任务卡 + 火漆封印状态徽章（已结/待审/紧急/可接/逾期），卡片底部撕边；全站只保留这一处高辨识元素。
- 布局：木质公告栏头 → 张贴栏分类签筛选 → 卡片网格（桌面 3 列 / 平板 2 列 / 手机 1 列）→ 详情页时间线 + 附件区。
- 约束：正文 ≥14px、对比度 ≥4.5:1；不使用 backdrop-filter（安卓真机性能）；动效仅保留火漆盖章 200ms，遵守 prefers-reduced-motion。
- 资产：uni-icons + 自绘 SVG 徽章/印章；羊皮纸与木纹用 CSS 渐变 + 轻量噪点；AI 插画仅登录背景/空状态/称号弹窗三处（imagegen 原创生成，≤200KB/张）。

状态：结构与图标（矢量）已落地；三处装饰性 AI 插画为可选打磨项，待用 imagegen 生成后放入 `apps/web/src/static/illustrations/`，不影响功能闭环。
